# Minimum Viable Product (MVP)

The first version of KnowledgeHub focuses on one complete user journey.

## User Flow

```
Register

↓

Login

↓

Upload document

↓

Document processed

↓

Embeddings generated

↓

Ask question

↓

Receive answer

↓

View citations
```

---

## Included Features

- User authentication
- Upload PDF/DOCX/TXT
- Document processing
- Semantic search
- AI-powered answers
- Source citations
- Chat history

---

## Not Included

- OCR
- Team workspaces
- Image understanding
- Audio transcription
- Multi-user collaboration
- RBAC
- Streaming responses
